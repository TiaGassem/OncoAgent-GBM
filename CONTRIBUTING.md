# Contributing
- Run `pip install -r requirements-dev.txt && pytest` before opening a PR.
- Never add a scientific fact by hand. Fetch it from a versioned source or cite a DOI/PMID you have checked.
- Any new SMILES must be added to `reference_compounds.py` with its expected formula.
- No clinical, diagnostic, treatment or patient-matching features. Research and education only.
- Report scientific errors with the issue template; corrections are logged in CHANGELOG.md.
